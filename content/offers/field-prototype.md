## What you get

- Working devices measuring on a real site, not only on the bench
- A dashboard showing live and historical data
- Unit cost at volume, and a certification roadmap
- Full source code and schematics, yours to keep

## The guarantee

Weekly demos with working hardware. If we slip a milestone, the following week is free.

## How it runs

We start with the measurement problem, not the enclosure. Getting voltage and current
right near mains is where the risk is; everything downstream is easier to change later.

## What we need from you

One technical contact, a description of what is being measured and where, and access to a
representative site if the connectivity is uncertain. If coverage there is unknown, we
test it before committing to NB-IoT or LTE-M.
