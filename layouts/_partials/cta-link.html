{{- /* Renders a link, or an honest unavailable state when the URL param is unset. The kit shipped href="[BOOKING LINK]", which a browser resolves as a relative path and serves a 404. This degrades safely instead. Two rules the unavailable state has to keep: 1. It renders in the CALLER's class, so an unclassed caller (the footer's social links) stays plain inline text and does not become a pill. 2. An ember pill downgrades to an outline pill — a dead control must not wear the page's primary accent — but it keeps full contrast rather than being dimmed to an unreadable ghost. The bracket sits OUTSIDE the control so it cannot break the pill's shape at phone widths. {{ partial "cta-link.html" (dict "url" .Site.Params.bookingUrl "text" "Book a call" "class" "pill-ember") }} */ -}} {{- $url := .url | default "" -}} {{- $text := .text -}} {{- $class := .class | default "" -}} {{- if $url -}} {{ $text }} {{- else -}} {{- $disabled := replace $class "pill-ember" "pill-outline" -}} {{ $text }} [link pending] {{- end -}}
